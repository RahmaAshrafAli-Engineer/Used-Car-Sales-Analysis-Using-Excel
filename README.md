# 🚗 Used Car Sales Analysis & Dashboard

## 📌 Project Overview

This project presents an interactive **Used Car Sales Analysis Dashboard** developed using **Microsoft Excel**.

The analysis focuses on exploring sales performance, profitability, customer feedback, vehicle characteristics, distributors, and sales agents using **Pivot Tables, KPIs, Charts, and Interactive Slicers**.

---

## 🎯 Project Objectives

* Analyze overall used car sales performance.
* Identify the most profitable manufacturers and car types.
* Analyze sales performance across distributors and sales agents.
* Explore profitability by energy type and manufacturing year.
* Analyze customer feedback.
* Build an interactive dashboard for easy data exploration.
